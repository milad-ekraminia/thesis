# validateForm

Contract: validate unique named rules, required values, basic string/number types,
minimum/maximum constraints, optional patterns, and unexpected supplied fields.

- **SLS 1:** Input container validation.
- **SLS 2:** Rule shape and duplicate-name handling.
- **SLS 3:** Required and type branches.
- **SLS 4:** Bounds and pattern evaluation.
- **SLS 5:** Unknown supplied-field detection.
- **SLS 6:** Aggregate validity and ordered error list.
